# Security and data handling

GenomQC processes local FASTQ files and does not upload sequence data.

- Do not commit research FASTQ files or participant identifiers.
- Store controlled-access data only in approved institutional locations.
- Review generated logs and manifests before sharing them externally because
  they contain local input paths.
- Report suspected vulnerabilities privately to
  `genomqc@outlook.com`.

This research-use workflow is not validated for clinical diagnosis.
